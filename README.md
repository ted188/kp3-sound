# Natural Growth

An audio-reactive generative visualizer. As music plays, an organic branching structure grows from the bottom of the canvas: bass drives its growth, while mid and high frequencies influence the spread of new branches.

## Getting Started

Open `index.html` in your web browser, choose a local audio file, and press Play. The visualization runs in the browser; audio files stay on your device.

## Running Locally

For projects with media files, use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Using VS Code Live Server extension
# Right-click index.html -> "Open with Live Server"
```
